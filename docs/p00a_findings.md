# P00a implementation and validation findings

Date: 2026-10-17. Engineering stage: bounded transition kernel complete. Full P00: incomplete. Scientific acceptance: untested.

Publication note: compact receipts and test logs are included under [evidence](evidence/README.md). Raw run histories, checkpoints, and original source snapshots remain local and are regenerated by the validation runner.

## Result

The Rust implementation and the separate Python interpreter agree on all emitted transitions for 112 fixed fixture runs: seven fixture families × 16 seeds × 12 epochs = 1,344 epochs and 1,216 accepted events. No fixture or seed was replaced. All 11 Rust integration tests passed. Clippy with warnings denied and formatting checks passed.

Primary evidence is [p00a-002/manifest.json](evidence/p00a-002/manifest.json), [independent_audit.json](evidence/p00a-002/independent_audit.json), and [checksums.json](evidence/p00a-002/checksums.json). Full states and events are in `artifacts/p00a-002/fixtures/suite.json` (local raw artifact). The bundle contains a frozen source copy, source hashes, executable hash, toolchain identity, and command output.

The original p00a-001 validation bundle is retained. It passed; p00a-002 adds a guard and regression check preventing Python optimization from disabling the independent auditor's assertions. This was a verification-hardening change, not a changed fixture, threshold, or retry of a failed scientific gate.

## What was verified

| Check | Result |
|---|---|
| Brute-force versus type-indexed Rust matching | Exact candidate, event, dependency, and final-state agreement |
| Independent Python interpretation | Exact candidate enumeration, priorities, selection, transition state, balances, dependency parents, and hashes |
| Atomic rejection | Full Experiment unchanged on binding/match/size caps and epoch/event-counter overflow |
| Compound-operation failure | No partially created entities, allocation changes, or resource/state changes |
| Local rewrite semantics | Negative-edge conflicts, resource contention, ordered 3/4-endpoint hyperedges, invalid dangling deletion |
| Fresh-process continuation | Seven resumed epochs exactly match uninterrupted continuation |
| No-op checkpoint branch | Zero-epoch continuation exactly matches source checkpoint |
| Damaged checkpoint handling | Truncated and altered payloads rejected |
| Checkpoint publication | Existing final destination not overwritten |
| Auditor adversarial checks | Changed priority/state/parents/events/rule rejected; Python -O rejected |

The two Rust matchers share their transition implementation. They alone would not establish transition correctness. The Python implementation uses separate match enumeration, operation evaluation, and scheduler reconstruction, and imports no Rust code.

## Limits

This is `p00a-local-closed-v1`: fixed contacts, closed resources, conservative node/adjacency conflicts, no environment supply or transport, and no scientific detector. The fixture repertoire is small and hand-designed. The Python checker validates successful fixture trajectories; grammar/cap rejection is covered by Rust regression tests rather than independent Python rejection replay.

Parallel checks run independent worlds in separate threads, not concurrent matching inside one world. No logging-disabled mode exists. Checkpoint tests cover corruption, no-overwrite behavior, and fresh-process continuation; they do not certify power-loss durability on arbitrary filesystems. Dependency traces establish execution bookkeeping, not causal necessity or biological lineage.

Growth/recycling is an engineered operation fixture, not spontaneous reproduction. No evidence for self-maintenance, heritable variation, adaptation, or improved search has been collected. P01 and E01 have not run.

## Reproduce

From the causal-alife project directory, with the pinned dependencies available:

```sh
cargo test --locked --offline
python3 scripts/validate.py artifacts/p00a-new-run
```

The output directory must not already exist. Failed runs remain inspectable. To audit the existing frozen trace directly:

```sh
python3 scripts/audit.py artifacts/p00a-002/fixtures/suite.json
```

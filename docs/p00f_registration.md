# P00f admission audit and frozen detector transfer panel

Registered 2026-10-19, before evaluating this panel. P00e protocol and analysis code are frozen. This is a disclosed engineering transfer challenge; it is not blinded external validation or a scientific census.

The 11 families and exact denominators are in `generalization_panel.json`: 8 new seeds × 2 identifier encodings × 11 families = 176 runs, each 12 epochs. Seeds only affect identifier permutation and native scheduling. They do not represent 176 independent structure families.

Five new active topology families cover connected chains, rings, stars, and arity-3/4 hyperedges. Each type-distinct component receives one joint native state increment per epoch. Minimum and maximum admitted component sizes remain 2 and 6. The generated shapes contain no P00e pair/star turnover fixture.

Negative/limitation cases cover a six-node frozen object, a three-node resource-only cycle, a four-node component that fragments once into two active pairs, two inert pair births from independent template controllers, a seven-node active component, and a four-node structural ring whose nodes act in separate events. Expected labels are fixed before running; they are predictions of the unchanged operational detector. In particular, the seven-node result must remain explicitly out of scope, and the asynchronous ring is an anticipated estimator disagreement rather than absence of active structure.

Each identifier encoding maps node and edge IDs injectively. The relabeled version permutes IDs from a deterministic seed-dependent affine map and reverses rule storage order; it changes no node/edge types, endpoint roles, operations, or resource inventory. Rule-slot references remain unchanged. Node-label invariance applies to AP labels and descriptor fingerprints. It does not assert identical scheduling priorities under relabeling.

Panel generation and independent Python reconstruction must agree on initial Experiments exactly. Rust reference/indexed matching must agree at every epoch. Python must independently replay every native event and all detector outputs. Compare paired AP labels and exact canonical topology fingerprints, retaining all mismatches. The detector's original source and protocol hashes are recorded and checked before analysis; no refit is allowed in this run.

The admission audit separately maps original P00 contracts to current evidence. Missing logging-mode equivalence and environment-to-detector integration are blockers even if this panel matches every prediction. Resource/time caps and pilot instrumentation are tracked as execution-readiness gaps. Budding/fission and heredity fixtures belong to their later registered assays rather than being retroactively demanded from AP.

The manifest must distinguish completed execution, valid independent replay, panel acceptance, P00 admission, and scientific status. An unfavorable transfer result is retained with the same denominator and cannot be repaired by replacing seeds or revising expected labels in this protocol version.

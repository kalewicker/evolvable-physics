# P00b intervention implementation and validation findings

Date: 2026-10-17. Engineering component: recorded interventions and matched controls passed. Full P00: incomplete. Scientific acceptance: untested.

Publication note: compact receipts and test logs are included under [evidence](evidence/README.md). Raw run histories, checkpoints, and original source snapshots remain local and are regenerated by the validation runner.

## Outcome

Implemented atomic source-bound state/resource interventions, explicit external-event receipts, dependency propagation, new-directory branch publication, and baseline/sham/target/unrelated/rescue fixtures. The native closed-world profile and rewrite laws remain unchanged. This component was implemented ahead of environment transport to isolate branching correctness against the already-verified substrate.

Primary evidence: [manifest](evidence/p00b-001/manifest.json), [intervention audit](evidence/p00b-001/intervention_audit.json), `artifacts/p00b-001/interventions/suite.json` (local raw artifact), and [artifact checksums](evidence/p00b-001/checksums.json). Source snapshots, source/binary hashes, toolchain identity, and test logs are retained in the same bundle. Earlier P00a evidence is preserved.

## Fixed denominators and results

- 16 Rust integration tests passed: 11 prior kernel regressions and 5 intervention tests.
- Formatting checks and Clippy with warnings denied passed.
- Original independent kernel audit: 112 runs, 1,344 epochs, 1,216 accepted native events, all verified.
- New controls: 2 fixture families × 16 seeds = 32 cases; 5 arms per case = 160 arms.
- Each source has 2 warmup epochs: 64 warmup epochs and 128 native events verified.
- Each arm has 8 continuation epochs: 1,280 continuation epochs and 1,792 native events verified.
- No seeds, arms, criteria, or failures were discarded or replaced.

The Python implementation independently applies the external operations, reconstructs receipts and writer dependencies, checks fixed fixture laws and prescribed controls, and replays every native continuation. Rust reference/indexed matching also agrees across the intervention continuations, though those matchers share native operation evaluation.

| Arm | State-arrest focal/control firings | Activation-relocation focal/control firings |
|---|---:|---:|
| baseline | 8 / 8 | 6 / 6 |
| sham | 8 / 8 | 6 / 6 |
| target | 0 / 8 | 0 / 6 |
| unrelated | 8 / 0 | 6 / 0 |
| rescue | 8 / 8 | 6 / 6 |

These fixed outcomes held for all 16 seeds in each family. Both manipulated nodes have equal type, state, matter, activation, and contact degree at branching. State arrest sets one node to a state with no applicable native oscillator rule. Activation relocation moves its remaining activation into an inert holder. The unrelated control applies the same operation to the other otherwise matched node.

Sham and immediate rescue have the same physical trajectories and native candidate priorities as baseline. Their event counters, dependency histories, and full checkpoint digests intentionally differ: external interventions remain recorded. An empty baseline request changes nothing, including metadata.

## Rejection and recovery evidence

Eight independent tamper checks rejected altered receipt parents, source identity, operation payload, rescue chain length, arm label, writer metadata, warmup state, and native laws. Rust checks cover atomic compound failure, stale sources, missing nodes, bad state preconditions, invalid resource moves, operation limits, event-counter overflow, and unknown JSON fields.

Fresh-process CLI checks applied both target interventions, resumed eight epochs, then separately applied and resumed the rescue branches. Full checkpoint payloads matched their expected continuations. All original source files remained byte-identical. Malformed, stale, and partially failing requests published no output directory. Existing branch directories could not be overwritten.

The CLI marks a branch complete only after writing its source checkpoint, branch record, and resulting checkpoint. Independent bundle checking verifies their digest relationships and the external transition. Consumers must reject incomplete manifests and retain ancestor receipts with later checkpoints.

## Scope and limitations

These engineered oscillator effects validate intervention machinery. They are not self-maintenance, damage recovery, reproduction, adaptation, or an ALife discovery. Rescue occurs immediately before native continuation, not after an extended damaged trajectory. The matched-control assumptions are known by construction here and must be justified separately for discovered structures.

Resource relocation is an external action, not native transport or a supply mechanism. No resource enters or leaves the world. The node-level provenance is conservative; it does not claim field-level causal necessity. Separate receipt bundles are required to resolve external event IDs: a checkpoint alone does not contain the full historical evidence. Filesystem power-loss recovery and arbitrary partial bundle-write fault injection remain unverified.

Environment sources/sinks and transport, calibrated structure/maintenance detectors, and the remaining P00 recovery cases are still pending. No P01 cost pilot or E01 scientific census has started.

## Reproduce

From the causal-alife directory:

```sh
python3 scripts/validate.py artifacts/p00b-new-run
```

The destination must be new. This runs the kernel and intervention checks together and retains source/evidence snapshots.

To inspect only the existing intervention traces:

```sh
python3 scripts/audit_interventions.py artifacts/p00b-001/interventions/suite.json
```
